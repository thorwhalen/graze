graze.media¶

Fetch one media file from a URL someone pasted: share link resolved, fetch guarded, bytes checked.

Three graze modules each answer one question about a caller-supplied URL; fetch_media() asks them in order, so an app does not keep its own copy of the glue (graze#18):

  1. graze.share_links – what does the link denote? A Dropbox or Google Drive share link becomes its direct-download URL; a folder link, or a link with no known rule (OneDrive, a Google Doc), is refused with the reason, before any network.

  2. graze.guarded – is it safe to fetch? Every hop is checked against the address policy (no localhost, private networks or cloud metadata), within a byte and a wall-clock budget.

  3. graze.content_kind – did we get the thing? The share host’s sign-in or preview page, and a ZIP where one file was meant, are refused instead of being kept as media.

>>> media = fetch_media('https://www.dropbox.com/scl/fi/a1/memo.m4a?rlkey=z&dl=0',
...                     expect_kind='audio')
>>> media.filename, media.provider
('memo.m4a', 'dropbox')

What it raises is one of FETCH_MEDIA_ERRORS, each with a message meant for the person who pasted the link:

>>> fetch_media('https://drive.google.com/drive/folders/1AbC')
Traceback (most recent call last):
    ...
graze.share_links.ShareLinkResolutionError: That google_drive link is a folder; share the single file instead...

Messages from this module name a link by redact_url() only (scheme, host, first path segment): share links carry bearer secrets in their path and query, and these messages are meant to be shown. Errors raised by graze.guarded itself still carry the full URL and the resolved address, so a web surface should word those itself rather than echo them.

Every keyword argument of graze.guarded.guarded_open() passes through (max_bytes, timeout, is_allowed_address, connector…), so tests and self-hosted setups use the same seams.

graze.media.fetch_media(url, *, expect_kind=None, refuse=('html', 'archive'), resolvers=None, **guarded_open_options)[source]¶

Fetch the one file url points at (a share link or a plain URL).

Parameters:

  • url (str) – What the person pasted. Surrounding whitespace is ignored.

  • expect_kind (Optional[str]) – 'audio', 'video', 'image'… when given, recognised bytes of another family are refused (audio and video containers pass for each other, see graze.content_kind); unrecognised bytes pass.

  • refuse (Iterable[str]) – Content families refused in any case (default DFLT_REFUSE).

  • resolvers (Optional[dict[str, Callable[[str], Optional[ResolvedShareLink]]]]) – Share-link adapters (default: graze.share_links.share_link_resolvers).

  • **guarded_open_options – Passed to graze.guarded.guarded_open().

Return type:

FetchedMedia

An HTML page and an empty body are always refused when expect_kind is given (that is graze.content_kind.assert_content_kind()’s rule); refuse adds families refused in any case.

Raises one of FETCH_MEDIA_ERRORS.
